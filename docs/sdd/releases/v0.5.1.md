# DeepViewer 0.5.1

DeepViewer 0.5.1 Build 91 macOS arm64 安装包已从固定源码和依赖全新构建，完成 Developer ID 签名、Apple 公证与本地产物检查。维护者于 2026-10-04 明确授权修复两个视觉问题后打包、公开发布、推送源码并合并 main；[PR #9](https://github.com/Duoasa/DeepViewer/pull/9) 已于 `2026-10-04T00:01:16Z`（北京时间 08:01:16）合并。`v0.5.1` tag 已推送；[GitHub Release](https://github.com/Duoasa/DeepViewer/releases/tag/v0.5.1) 于 `2026-10-04T00:09:27Z`（北京时间 08:09:27）正式公开为 Latest，draft=false / prerelease=false。两个公开资产大小与 digest 匹配本地，公开下载检查通过，main 合并 CI success。完整视觉和真实用户环境仍保留以下人工验收边界。

## 来源与修复

- 按 [DV-0034](../specs/DV-0034-brand-visual-051/spec.md) 恢复 v0.3.3 / Build 75 新会话待机视觉。48px 高、50% opacity 的原双 path SVG、1s steps 光标闪烁、40px 图文间距和 24px / 32px 系统字体规则回到旧基线；待机区独立于底部常驻 composer 居中，保留 reduced-motion、slot、草稿与会话状态。
- 已证实图标源 PNG 铺满 1024 画布，启动后的运行时 PNG Dock override 又替换原生 bundle 图标。修复使用原鲸鱼 SVG 的 `DeepViewer.icon`，由 Apple `actool` 编译 `Assets.car`、完整 legacy ICNS 与系统外观 / mask / 透明边界；bundle 与开发壳使用同一图标名，移除运行时覆盖。没有缩小整张旧图或加运行时尺寸补丁。
- 最终签名 app 的 catalog 包含 Aqua、DarkAqua、Tintable 与原 Whale vector；ICNS 有 10 个有效 renditions，1024px 表示的 alpha>127 边界为 `[100,100,923,923]`，About PNG 与 ic10 字节相同，没有残留 `DeepViewerDockThemes`。这些是实际资源证据，不代替实际 Dock 视觉验收。
- 继续使用 DSH `0.2.0-rc.2` / `639ed015397290b3745d163aafe02ffee4aa3f84`。本次没有升级内核或内置插件，不改变 agent loop、用户数据与字体权限；保留 [0.5.0](v0.5.0.md) 迁入的 HMR 修复、产品数据隔离与原生功能，不把迁入功能记为 0.5.1 新增。
- 产品版本为 0.5.1，previewRelease 为 0.5.1-preview.1；正式 packager 从 90 单调递增为 Build 91。原生 `.icon` 编译需要 Xcode 26 或更新版本，本机构建工具链为 Xcode 26.6 / 17F113。
