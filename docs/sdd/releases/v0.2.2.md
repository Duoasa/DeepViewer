# DeepViewer 0.2.2（Build 1）

DeepViewer `v0.2.2` 将包内唯一核心升级为官方 DeepSeek Harness
`0.1.0-rc.8`，并针对 rc.8 的 host/client 构建契约重新适配与验证订阅、代码/
静态网页预览两个 Active 插件。该版本不扩大桌面权限或改动产品界面，保持
0.2.1 作为回滚入口。

## 更新内容

- 核心锁定官方不可变标签 `dsh-v0.1.0-rc.8` 及提交
  `141eb6fef83422698aef7a981029e843e8161534`。
- 引入上游多模态/图片输入、文件与会话引用、可安装 Claude/Codex 子代理
  bundle、持久 PowerShell、并发 Web Search、子代理唤醒以及启动/下载优化。
- 同步上游图片载荷、流式取消、自定义 OpenAI 兼容网关、搜索、工具显示与
  布局修复。
- `@deepviewer/dsh-plugin-preview@0.1.0` 的九个 DeepSeek peer 全部锁定 rc.8；
  受控同步改为先构建 host/client 契约，再以隔离 manifest 构建第一方插件。
- `dsh-plugin-subscriptions@0.3.1` 保持版本不变，peer、manifest、Web client、本地化
  用量适配、禁用降级与包体清单自动检查通过。

## 会话数据边界

- DeepViewer 基础 bundle 继续使用 `@deepseek-ai/dsh-session-persistence-jsonl`，默认
  0.2.1 会话不执行数据迁移。
- rc.8 的可选 SQLite 物理 schema 为 17，上游不提供从早期预发布 schema 的原地
  迁移。自定义 SQLite 用户必须保留旧数据库，为 rc.8 新建数据库，或重装
  [0.2.1](https://github.com/Duoasa/DeepViewer/releases/tag/v0.2.1) 读取旧数。DeepViewer 不会
  自动删除、覆盖或转换这些数据。

- arm64 与 x64 应用各有 34 个 Mach-O 通过严格嵌套签名验证；两个 DMG 均完成
  Developer ID 签名、Apple notarization、ticket staple、Gatekeeper 与 `hdiutil verify`。

  `Contents/Resources/harness`；内核和两个插件的版本/许可与 Runtime manifest 一致。
- 每个包体的 ASAR 只包含 16 个允许列表条目，个人路径、敏感文件名和当前环境凭据值
  审计通过。公开记录不保存签名身份、证书指纹、公证提交标识或凭据值。
