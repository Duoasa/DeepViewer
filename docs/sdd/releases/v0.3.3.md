# DeepViewer 0.3.3

This public ARM64 release advances from the previous public 0.2.5 package. The functional changes, plugin provenance, and DeepViewer adaptations are summarized in the [English README](../../../README.md) and [中文 README](../../../README.zh-CN.md). The only bundled Harness core remains official `0.1.5-rc.2` plus the reproducible [0.3.3 source patch](../../../upstream/snapshots/v0.3.3/README.md); Electron is pinned to 43.4.0.

## Release boundary

- Work/Chat separation and cold-list restoration, workspace-backed file attachments, first-party model capability editor, Better Sidebar integration, system network routing and local-network consent, progressive disclosure, and fixed installed/development data directories are included.
- The subscriptions plugin `0.3.1` and Better Sidebar `0.19.1` remain third-party MIT projects adapted for this desktop version; the reasoning plugin `0.1.0` is first-party. The Taskboard integration is removed.
- DV-0031 AC-005 remains `Pending Manual`: final migrated-session, settings, and attachment UI acceptance belongs to the maintainer. Real-account subscriptions, paid search, and provider-specific multimodal capabilities are outside this automated release check.
- This is an arm64-only DMG. Historical public releases remain available as rollback sources; their app-data layout differs. Back up existing data before a major upgrade.
