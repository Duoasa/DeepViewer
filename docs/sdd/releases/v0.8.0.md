## Kernel

DeepSeek Harness moves from `0.2.1-rc.2` / `687f282e8625c6b8d11ff58211a90524be2e4317` to `0.2.1-rc.5` / `b830ec950faba0a46dda564be3e2d854afed94f1` (tag `dsh-v0.2.1-rc.5`) through [DV-0037](../specs/DV-0037-dsh-021-rc5/spec.md). CI checks out that commit.

rc.3 through rc.5, as described by the upstream release notes:

- rc.3 adds More menus in the sidebar, session view, and right panel, so entries can be pinned or hidden. It adds `@deepseek-ai/dsh-client-ui-entry-customization`, registered in the web-app patch as `entry-customization`. It fixes a New Session draft being dropped. The DeepSeek API key adapter follows the official `/models` list.
- rc.4 stops writing ACP diagnostics to stdout. The MCP client returns an empty resource list when the server does not declare the resources capability. It also fixes a view-tab tooltip.
- rc.5 lets the web UI render custom reasoning blocks. The `conversation.chat.reasoning.body` slot gains `rawText` on owner props, and `text` is the display text.

Upstream did not mark a breaking change for this rc line. The reasoning-body props note applies to custom reasoning renderers. DeepViewer does not render that slot.

## DSH-to-Figma

The bundled plugin stays at DSH-to-Figma 0.2.1 (`ffc4d3a1c59d8c9e53261e4e9d8a5e8e6e174412`). Its peer range does not include `0.2.1-rc.5`, so native staging is expected to fail with `Incompatible Figma dependency: @deepseek-ai/dsh-home-paths@0.2.1-rc.5`. That check is unchanged.

The upgrade to DSH-to-Figma 0.3.1 is pending. Upstream pull request [Duoasa/DSH-to-Figma#7](https://github.com/Duoasa/DSH-to-Figma/pull/7) is not yet published. When 0.3.1 is published, it will be added to this same branch. This record does not include that upgrade.
