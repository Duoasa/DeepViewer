# DeepViewer 0.7.1

维护者于 2026-10-19 确认升级开发版“界面没问题”，并授权 0.7.1 arm64 安装包、GitHub Release、源码 main 合并及双语 README 更新。当前正在准备，尚未发布。

## 内容与来源

- DSH `0.2.1-rc.2` / `687f282e8625c6b8d11ff58211a90524be2e4317`，Electron `44.7.0`，Cordis `4.0.5`，随包 pnpm `11.28.5`。
- 保留 DeepViewer 前端、字体、图标、待机动画与 Work/Chat 产品行为；适配新版会话、草稿、Synapse、插件构建与更新策略。Agent loop 未修改。
- 修复 Python 相对符号链接与 pnpm 运行时布局，沿用版本无关的安装/开发数据目录。
- 内置 subscriptions 0.3.1、model-capabilities 1.0.2、adapter 0.7.1；版权和许可证保留。

## 验证

升级源代码的 PR #10 与最终 main CI 已通过。167 契约、121 bounded smoke、202 前端组件回归、76 适配测试以及 Host、模型扫描、隔离 ASAR payload 均有证据，见 [DV-0035 verification](../specs/DV-0035-dsh-021-rc2/verification.md)。发布产物需重新构建，并补充最终实际签名包、公证、挂载与公开下载证据。

## 人工验收和发布边界

维护者已确认升级开发版界面正常。旧完整 UI 自动化遇到空 DOM 引用，不计为通过；真实账户、未明确覆盖的交互、迁移的真实会话/设置/附件与 Office 用户字体权限仍保留独立人工验收。规格保持 Implementing，公开发布授权不将这些项自动标记为 Pass。

公开资产仅为 DMG 与本版本新生成的 SHA256SUMS.txt。ZIP、blockmap 和自动更新 feed 不公开，已有历史版本保留。README 截图继续明确标为 0.3.3 历史参考，不用历史截图代表本版本。
