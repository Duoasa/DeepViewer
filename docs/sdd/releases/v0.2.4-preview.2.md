# DeepViewer 0.2.4 集成式灵动岛源码预览版

本预览版在 `v0.2.4-preview.1` 基础上，将 QuotaView 同款单任务灵动岛从独立置顶表现调整为
无缝集成在 DeepViewer 主内容顶栏中的透明状态层。它仍只使用当前选中 Harness 会话作为
权威数据源，不增加第二套连接，也不扩展为多任务岛。

## 隔离边界

- 独立分支：`DV/preview-0.2.4-activity-island`
- 预发布标签：`v0.2.4-preview.2`

- 源码入口：`https://github.com/Duoasa/DeepViewer/tree/v0.2.4-preview.2`
- 不合并或移动 `main`、`v0.2.3`、`v0.2.4-preview.1`，不改变 0.2.3 的公开安装资产。

## 本轮内容

- 灵动岛锚定主内容区标题栏中央，随侧栏、详情栏、窗口尺寸和主窗口显隐变化重新定位。
- 移除岛的底色、边框、模糊与容器阴影，支持浅色顶栏深色文字和深色顶栏浅色文字。
- 当前会话 token 摘要固定在原顶栏内，并与“对话 / 轨迹”标签文字行对齐。
- 设置页直接复用岛的真实 WebGL renderer 展示粒子球与波澜光晕，不再使用 CSS 近似图。
- 展开态到紧凑态以几何中心为固定点同时收缩四边。
- 使用普通透明 child window；主窗口失焦时隐藏，聚焦时恢复，不使用原生 `panel`、
  always-on-top 或跨 Space 置顶。

## 源码编译

要求 macOS、Node.js 24 或更高版本，以及 pnpm 11.19.0。

```sh
git clone --branch v0.2.4-preview.2 --depth 1 https://github.com/Duoasa/DeepViewer.git
cd DeepViewer
pnpm install --frozen-lockfile

git clone https://github.com/deepseek-ai/deepseek-harness upstream/deepseek-harness
git -C upstream/deepseek-harness checkout b150a551b8d465e31e418e1b2eaf5e79bbb7d28e
pnpm --dir upstream/deepseek-harness install --frozen-lockfile
pnpm --dir upstream/deepseek-harness run build:official
pnpm --dir upstream/deepseek-harness run release:pack --family vendor --out dist/deepviewer/vendor
pnpm --dir upstream/deepseek-harness run release:pack --family dsh --out dist/deepviewer/dsh

pnpm --filter @deepviewer/desktop runtime:arm64  # Apple Silicon
# pnpm --filter @deepviewer/desktop runtime:x64 # Intel Mac
pnpm desktop:dev
```
