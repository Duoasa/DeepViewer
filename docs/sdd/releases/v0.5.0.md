# DeepViewer 0.5.0

本记录是维护者明确授权准备的 0.5.0 macOS arm64 正式签名安装包候选。维护者于 2026-10-03 要求打包并发布到 [Duoasa/DeepViewer](https://github.com/Duoasa/DeepViewer)、推送源码并合并 main。最终打包与公开发布证据尚待补齐；此处不把版本目标写成已发布事实。

## 来源与变更

- 固定导入 [Duoasa/scoder](https://github.com/Duoasa/scoder) main `e277adc6ce512655095e6f65c63bdc72d24bae95`，源版本为 Scoder 0.7.0 Build 43。DeepViewer 的 Git、SDD 和历史公开发布记录保留，Scoder 发布与用户数据不作为 DeepViewer 发布或迁移来源。
- 官方 DeepSeek Harness 固定 `0.2.0-rc.2` / `639ed015397290b3745d163aafe02ffee4aa3f84`，使用原生 Electron 44 DesktopHost 和产品 adapter，不回放旧 0.1.5 整文件覆盖、不改 Agent loop。
- 恢复 DeepViewer 品牌、原始 PNG/ICNS/SVG、欢迎与思考文案、包名、更新目标、稳定/开发数据目录，移除 Scoder 鸭形象。
- 迁入原生 Work/Chat、文件交付、编辑器/Git、Synapse 会话地图、网络授权和隐私策略。Subscriptions 0.3.1、model-capabilities 1.0.2 和 DeepViewer adapter 为应用内置模块；旧 reasoning/Better Sidebar 挂载由新模块及官方能力承接。
- 修复文件 metadata 变化造成的 renderer 白屏：ctime-only 变化不再通知卸载未变更模块，字节变化与 mtime 构建戳仍触发真正的热更新。开发 watcher 忽略 metadata-only 变化与相同字节重写。
- 上游版权、MIT/OFL、第三方字体及编辑器许可证保留在源码和打包闭包中。

## 已验证范围

累计迁入证据与可复现命令见 [DV-0033 verification](../specs/DV-0033-scoder-native-rebase/verification.md)。已完成冻结依赖、固定核心/adapter/模型能力/订阅/主入口/独立 runtime 构建和 typecheck；初始 smoke 76 项、模型能力 52 项、UI 回归 176 项、RPC/文件保护 12 项，以及 Synapse Host/Client/native seams 7/11/6 项通过。
