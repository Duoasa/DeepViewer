# DeepViewer 0.2.3（Build 1）

该版本将 DeepViewer 内置核心升级到官方 DeepSeek Harness `0.1.1-rc.2`
（提交 `b150a551b8d465e31e418e1b2eaf5e79bbb7d28e`），并适配内置订阅与预览插件、
rc.2 受控 UI 覆盖和独立的 DeepViewer mark/name 品牌槽位。

两个架构的最终 DMG 已完成 Developer ID 签名、Apple 公证、ticket staple、Gatekeeper、
磁盘镜像验证和只读挂载应用回读。`v0.2.3` tag 与公开 GitHub Release 已发布为 Latest；
两个 DMG 和校验清单的远端大小及服务器端 SHA-256 均与本地最终资产一致。

## 构建与验证

- 从固定 rc.2 checkout 生成 9 个 vendor 与 227 个 DSH release-pack tarball；两个架构的
  Runtime、staging、应用目录和 DMG 均在候选封包前重新生成。
- 桌面 15 个测试文件 / 106 项测试、TypeScript、桌面 production build、DSH Host/Client/Web
  official build，以及 284 个 DSH GUI 测试文件（3998 passed / 1 skipped）通过。
- arm64 与 x64 应用各有 34 个 Mach-O 通过 Developer ID 严格嵌套签名验证；主程序架构
  分别回读为 `arm64` 与 `x86_64`。
- 两个包体的 ASAR 均只有 16 个允许列表入口，个人路径、凭据值和 Runtime 符号链接逃逸审计通过。
- 两个 DMG 均获得 Apple `Accepted`，完成 ticket staple/validate、`hdiutil verify`、Developer ID
  磁盘镜像签名、Gatekeeper 与只读挂载应用评估；应用图标资源与项目 `DeepViewer.icns` 内容一致。
- 维护者提供的 3064×1970 原始 PNG 按字节不变保存为 `Resources/DeepViewer-0.2.3.png`，并用于
  双语 README 顶图与 0.2.3 版本章节；SHA-256 为
  `8deceffeef445165b7878ec58aa13af89aaf8104284428be1ed2aa211839dcaf`。
