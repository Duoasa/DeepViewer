## 全新构建与隐私门禁

- arm64 与 x64 在各自封包前清理 Runtime、staging、`.app` 输出和旧 DMG。
- 应用只从包含 `.desktop`、`assets`、`package.json` 的 allowlist staging 目录封包；包管理器工作区元数据和历史输出不会进入 ASAR。
- Runtime 构建移除 pnpm 状态文件，并把构建机项目路径和主目录替换为稳定的非个人占位路径。
- 两个最终 `.app` 均通过 `release-audit.mjs`：检查 ASAR allowlist、敏感文件名、开发者绝对路径与当前环境中的高置信度凭据值；日志不打印秘密原文。
- 本次资产为 `0.1.1` 源码树生成的全新包，不复用或改名 `v0.0.1` 的 `.app`、Runtime、DMG 或校验清单。

## 验证范围

- `pnpm typecheck` 通过。
- 7 个测试文件、32 项测试全部通过。
- main、preload、renderer production build 通过。
- arm64 与 x64 主可执行文件分别确认为原生 `arm64`、`x86_64` Mach-O。
- 两个包的 `CFBundleDisplayName` 为 `DeepViewer`，版本为 `0.1.1`。
- 两个最终 DMG 均通过 `hdiutil verify`、Developer ID 签名验证、Apple 公证、
  `stapler validate` 和 Gatekeeper 基础评估；GitHub 新下载副本带 quarantine 后同样通过，
  远端 digest、大小和 `SHA256SUMS.txt` 全部一致。
- 依据 SDD 验证职责，本次发布收尾未由开发代理执行应用交互测试；维护者负责最终手动验收，并已反馈当前版本初步通过。

## 用户可见变化

- 原生 macOS 交通灯进入应用表面，侧栏完整收起、全屏按钮补位、全宽拖动区和 48px 顶部安全区与 Codex 行为对齐。
- 系统应用名、窗口名、Dock 与安装包身份统一为 `DeepViewer`，使用 macOS 26 图标源。
- 启动等待页显示居中的 DeepViewer Logo 与光标横线动效；插件加载阶段显示静止 Logo 和 `Loading Plugins...` 文字流光。
- 英文与简体中文 README 加入产品图、应用图标、架构下载和校验入口。

## 已知限制

- x64 包已完成架构检查和 Apple Silicon + Rosetta 验证，但尚未在真实 Intel Mac 上验收。
- DV-0003 的无密钥流式任务、特殊路径/clean environment 与安全 UI 走查尚未全部完成。
- DV-0006 的减少动态效果和 Runtime 失败态仍等待维护者专项人工验收。
- Windows、自动更新和稳定版支持承诺不属于本版本。

- DV-0004 与 DV-0005 的验收条件已通过，并随本公开版本进入 `Released`。
