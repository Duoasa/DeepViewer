# DeepViewer 0.2.1（Build 1）

DeepViewer `v0.2.1` 将内置核心升级为 DeepSeek Harness `0.1.0-rc.7`，并发布首批固定版本
DSH 插件集成：订阅提供方与代码/静态网页预览。该版本同时交付全局设置与关于页、Agent 产出
默认内置预览、Finder 原生操作，以及预览侧栏和 DeepViewer 品牌界面的多轮交互精修。

## 更新内容

- 内置核心从 rc.5 升级到 DeepSeek Harness `0.1.0-rc.7`；后续核心升级必须检查插件登记表中的
  全部 `Active` 插件。
- 设置改为窗口级全局页面，新增“关于 DeepViewer”并展示应用版本、Build 与 DSH 核心版本。
- 模型页以“API”和“订阅”两个板块组织提供方；订阅用量按剩余百分比填充并使用三级余量颜色。
- 新增可调宽度的右侧预览栏，支持工作区代码、隔离静态网页、基础浏览器导航、上下区域拖动和
  默认窗口三分之一宽度。
- Agent 产出单击默认使用内置预览；原生右键菜单提供“在 Finder 中显示”和“在 DeepViewer
  中预览”。
- 更新侧栏 DeepViewer 标志、欢迎内容、120px 启动动画、手动侧栏控制及浅色/深色可读性。

## 插件与安全边界

- 插件来源、版本、许可、peer 解析、manifest、Web client、降级路径与 Runtime 清单均已固定并
  记录在 [`dsh-plugins.md`](../integrations/dsh-plugins.md)。
- 插件不会在运行时下载或修改已签名的 `Contents/Resources/harness`；缺失、禁用或不兼容时
  继续启动内置核心。
- 订阅插件的凭据仍位于隔离 DSH home 的原子 `0600` 文件。维护者批准其作为 `v0.2.1` 公开
  预览版的临时等价方案；稳定版前仍需迁移到 macOS Keychain 或重新完成安全评审。
