# DeepViewer 0.2.5 Preview 1

本轮基于 GitHub 发布的 v0.2.3 适配官方 DSH `0.1.5-rc.2`，不包含 0.2.4 灵动岛开发线。
GitHub 标记为 Pre-release；v0.2.3 继续作为 Latest，历史 Intel 安装包保留。

## 变化

- 仅支持 macOS 12 或更新版本的 Apple Silicon arm64。
- 采用官方文件与网页预览，保留右上角展开、收起和全屏操作；停用原 DVP-0002 插件。
- 适配订阅插件的 Host RPC、客户端依赖、ToolCallId 与 Responses 可选工具参数。
- 将会话输入框底部留白统一为 32px。
- 公开包使用 `DeepViewer Preview/0.2.5-preview.1` 独立数据目录，不自动导入旧版或开发版数据。

## 固定输入

- DeepViewer 基线：`25de065bc8fbee885696c4c3da0ca14158fa687b`（v0.2.3）。
- DSH：`fb2c4b9e698e30edb738bca4cf0618587db7d203`（dsh-v0.1.5-rc.2）。
- Electron 43.4.0，应用 0.2.5 / Build 1，订阅插件 0.3.1。
- 从受控覆盖与官方构建重新生成 9 个 vendor、265 个 DSH tarball，再安装全新的 ARM Runtime。
- 发布分支：`codex/dsh-0.1.5-rc.2-arm64`；不合并到 main。

## 资产与验证

ARM64 DMG 已生成并完成 Developer ID 签名；Apple 公证正在执行。最终 SHA-256 在装订公证票据后计算。

- 35 个 Mach-O 签名验证通过；16 项 ASAR allowlist 与包体隐私检查通过。
- 实际签名应用冒烟通过：独立 Preview 数据目录、Host 启动、官方预览资源、原生窗口控制、空账户订阅状态 RPC 200、未认证请求 401、日志脱敏、退出后 Runtime 结束。
- 冒烟未出现 renderer error；当前空工作区产品图已同步至双语 README。
