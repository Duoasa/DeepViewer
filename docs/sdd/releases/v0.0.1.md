# DeepViewer v0.0.1

DeepViewer `v0.0.1` 是首个公开的 macOS 双架构封包预览版，用于验证 Apple Silicon 与 Intel 安装产物、内置 Harness Runtime 和现有 Web surface 的桌面运行路径。它不是稳定版，也不代表 UI 与功能定制已经开始或完成。

## 验证范围

- arm64 产物在 Apple Silicon macOS 原生启动并加载真实 Harness Web surface。
- x64 产物在 Apple Silicon macOS 通过 Rosetta 启动并加载真实 Harness Web surface。
- 两个 DMG 均通过 `hdiutil verify`。
- Runtime 启动、随机 loopback 端口和退出进程回收路径已通过当前自动化或本机冒烟验证。
- 英文与简体中文 README 已提供安装、架构选择、校验方法和安全限制。

完整验收矩阵见 [DV-0003 verification](../specs/DV-0003-desktop-packaging-spike/verification.md)。

## 已知限制

- 应用未使用 Apple Developer ID 签名，也未经过 Apple 公证；macOS Gatekeeper 可能阻止首次启动。
- Intel DMG 已通过 Rosetta 验证，但尚未在真实 Intel Mac 上完成验证。
- 无密钥流式 Agent 任务、失败/重试 UI、安全自动检查、非 ASCII 路径与无全局开发工具账户仍有待完成。
- 当前产物包含较完整的运行时依赖，体积尚未优化。
- Windows 客户端、自动更新和正式发行链路不属于本版本。

## 规格状态判断

`v0.0.1` 的公开发布证明双架构安装资产已经可供测试，但不会替代尚未完成的验收条件。因此 DV-0003 继续保持 `Implementing`；待剩余证据齐备后再进入 `Verified`。UI 与功能改造等待项目负责人提供并批准方案，Windows 适配继续后置。
