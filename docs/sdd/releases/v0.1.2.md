# DeepViewer 0.1.2（Build 2）

DeepViewer `v0.1.2-build.2` 保留应用版本 `0.1.2`，将 macOS bundle build number 提升为
`2`。该热修复在原有双列窗口、固定输入框、新会话欢迎内容和侧栏原生材质基础上，补充了
安全的系统浏览器外链通道，以及本地交付物的 `finder中显示` 原生菜单。双架构安装包已经完成
全新构建、隐私审计、Developer ID 签名、Apple 公证、票据装订、维护者验收与远端回读验证，
并于 2026-08-17 发布为 GitHub Latest Release。原 `v0.1.2` Release 保留用于回滚。

## 更新内容

- 保留内部导航白名单和新窗口拒绝策略，只把 `http` / `https` 外链交给系统默认浏览器。
- 新增原生右键菜单；对 `file://` 或 Harness 提供的绝对文件路径显示 `finder中显示`，调用
  macOS Finder 打开所在文件夹并选中文件，同时提供复制文件路径操作。
- 正式包 bundle build number 更新为 `2`，并修复 pnpm 11 下 release Runtime 脚本的显式调用。
- 将 macOS 主窗口整理为侧栏与 Chat 两列结构，各列独立拥有系统安全区。
- 把模型使用统计移动到 Chat 顶部安全区居中显示，输入框在新会话、思考和完成状态保持
  `32px` 统一底部基准。
- 新增完整 Chat 画布居中的新会话欢迎内容：48px 半透明 DeepViewer 动画图形和本地化
  “让我们做点什么”文案。
- 侧栏使用受控内联 DeepViewer SVG，并完成浅色/深色、聚焦/失焦、原生磨砂材质、遮罩连续性、
  固定侧栏按钮和浅色原生窗口控件可读性处理。
- 新增可追踪的上游 UI 覆盖同步与重建机制，避免产品定制只存在于被忽略的 checkout。
- 建立开发、ARM 本地预览和正式双架构发布三个显式层级，开发数据与正式数据隔离。
- 正式和预览封包均强制同步受控覆盖，并使用文件级 staging allowlist，避免本地未跟踪文件、
  source map 或重复文件进入最终 ASAR。
