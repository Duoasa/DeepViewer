# DeepViewer v0.1.2

DeepViewer `v0.1.2` 是完成 macOS 双列窗口结构、固定输入框基线、新会话欢迎内容与侧栏
原生材质适配的公开预览版。双架构安装包已经完成全新构建、隐私审计、Developer ID 签名、
Apple 公证、票据装订与完整性验证，并于 2026-08-17 发布为 GitHub Latest Release。

## 更新内容

- 将 macOS 主窗口整理为侧栏与 Chat 两列结构，各列独立拥有系统安全区。
- 把模型使用统计移动到 Chat 顶部安全区居中显示，输入框在新会话、思考和完成状态保持
  `32px` 统一底部基准。
- 新增完整 Chat 画布居中的新会话欢迎内容：48px 半透明 DeepViewer 动画图形和本地化
  “让我们做点什么”文案。
- 侧栏使用受控内联 DeepViewer SVG，并完成浅色/深色、聚焦/失焦、原生磨砂材质、遮罩连续性、
  固定侧栏按钮和浅色原生窗口控件可读性处理。
- 新增可追踪的上游 UI 覆盖同步与重建机制，避免产品定制只存在于被忽略的 checkout。
- 建立开发、ARM 本地预览和正式双架构发布三个显式层级，开发数据与正式数据隔离。
- 正式和预览封包均强制同步受控覆盖，并使用文件级 staging allowlist，避免本地未跟踪文件、
  source map 或重复文件进入最终 ASAR。
