# DeepViewer 0.2.2（Build 2）

DeepViewer `v0.2.2-build.2` 保留应用版本 `0.2.2` 与官方 DeepSeek Harness
`0.1.0-rc.8`，将 macOS bundle build number 提升为 `2`。该热修复为全部内置 Web
启动路径传入 rc.8 的 `--no-open`，避免应用启动时额外唤起系统默认浏览器；Harness 仍只监听
随机 `127.0.0.1` 端口并由 DeepViewer 窗口加载。

## 修复范围

- 核心、订阅插件、预览插件及逐级降级路径统一使用同一个 Web 参数生成器。
- 每条路径都只传入一次 `--no-open`，不改变 Runtime origin、健康检查或应用内导航。
- 不改动 rc.8 核心、两个插件、会话格式、桌面权限与现有界面。
- 原 `v0.2.2` Build 1 tag、Release 与资产保留为历史回滚入口。
