# 自定义模型思考强度原生插件

维护者直接授权以原生插件实现思考强度选择；仅冒烟，实机验收由维护者执行。

- R-001：DVP-0003 使用 DSH 0.1.5-rc.2 的原生 Models provider-card slot、settings Remote 和现有模型选择器，不修改上游 Agent/选择器。
- R-002：逐提供方、逐模型声明 reasoningEfforts，支持档位与接口值映射、关闭及恢复继承；不凭模型名批量猜测能力，不自动修改个人配置。
- R-003：仅修改所选模型的能力声明；CAS 修订保护拒绝并发覆盖；手动编辑不接触凭据；扫描在 Host 内按已保存提供方解析凭据并发起限额请求，密钥不传入 Client。写入被脱敏模型列表时拒绝，避免损失秘密配置。
- R-004：作为有 manifest、Host/Client、bundle patch、MIT 的内置插件，纳入开发 staging 与 ARM Runtime；支持停用和缺包降级。
- AC-001：原生 client 构建和 manifest/patch 入口冒烟通过。
- AC-002：临时模型配置保存/恢复与旧字段保留、无效映射拒绝冒烟通过。
- AC-003：隔离 Host 能加载插件且原生模型目录能反映配置档位；不调用外部 API。
- AC-004：界面、easyrouter 实际档位效果由维护者验收，Pending Manual。

当前 Active 插件为 DVP-0001 与新增 DVP-0003；核心 pin 不变，DVP-0002 保持 Disabled。默认不封包、不发布、不改已签名 app。

## 2026-09-16 通用扫描扩展（维护者直接授权）

- R-005：扫描入口使用原生 settings.models.provider-card，挂在对应聚合 API 卡片；新增保存后显示未扫描提示，已有提供方可重新扫描。不使用提供方品牌或模型名单特判。
- R-006：支持 OpenAI Chat Completions 兼容接口；扫描模型目录并探测文本可用性及 low/medium/high，非法档位作对照。未知、限流、超时、预算不足不得当作不可用或已确认档位。
- R-007：扫描需显式启动，展示请求上限、进度、停止及逐项结果；探针输出最多 1 token、并发 2、最多 200 个模型，单模型最多 7 次请求，不自动加大预算或后台重复收费。Host 同时只运行一个扫描。
- R-008：报告按提供方保存在本机，配置变化后标记过期；应用需显式选择，仅排除确定失败/非文本项，保留未扫描和不确定项，保存已确认档位；写回带 CAS 并备份目标模型数组，可恢复。密钥仅发往原配置地址，禁止重定向。
- AC-005：模拟两个不同聚合 API 的扫描、取消、过期、结果应用/恢复及请求参数限制冒烟通过；不再调用真实 API 批量验证。
- AC-006：每个提供方卡片显示自己的扫描状态与结果；界面验收 Pending Manual。

## 2026-09-17 图片输入扩展（维护者直接授权，Implementing）

- R-009：在对应 API 卡片扫描文本可用性、思考档位和图片输入。每个文本可用模型至多增加一次内置合成图片识别请求；不发送用户图片。请求总数硬限制 7，其他限制不变。正确识别随机色块顺序才确认支持；明确拒绝图片记为不支持，其余待确认。不按模型名猜测图片输入能力。
- R-010：明确区分图片输入与图片生成；扫描确认后通过原生模型 `input: [text, image]` 配置开放上传。未知/失败不清除已有人工配置；支持按模型手动选择继承、仅文本或文本和图片，保留其余字段与 CAS 保护。旧扫描报告过期，重扫后显式应用。
- AC-007：模拟图片识别成功、图片被忽略、明确不支持、限流、预算与取消，以及应用/恢复、未知保留和手动配置的有界冒烟通过。
- AC-008：隔离 Host 配置和原生 resolveModelInfo 反映图片能力；真实 API 图片上传与识别由维护者验收，Pending Manual。默认不批量调用真实 API、不封包、不发布。

## 2026-09-21 Responses 扫描适配（维护者直接授权）

- R-011：在原扫描入口支持 openai-responses，使用 /responses、input、reasoning.effort、max_output_tokens 与 Responses SSE/JSON；不回退 Chat Completions，不发送用户数据，store=false。
- R-012：Responses 单次输出上限固定 64 token，在启动前展示；仍最多 7 请求、15 秒、并发 2。不自动提高预算，创建事件和空响应不能确认可用，失败流、预算耗尽保持保守结论。模型目录声明不代替 Responses 实际调用检测。
- R-013：区分接口 404 和明确 model_not_found；权限受限、限流、预算、未知错误不移除模型。无 /models 的兼容端可仅扫描已有配置模型。旧报告因规则版本变化过期。
- AC-009：模拟 Responses SSE 分片、JSON、图像、档位、失败、错误分类、取消、目录回退与服务应用/恢复通过；原 Chat Completions 扫描回归通过。开发版重构并重启；真实 API 扫描与界面由维护者验收。
