# DV-0010：全局设置与关于 DeepViewer 页面

## 摘要

把现有居中模态设置框改为占满主窗口的全局设置页面，采用类似 Codex 的左侧导航与右侧内容
结构；在导航底部新增“关于 DeepViewer”，以简洁品牌页展示应用图标、名称、产品说明、当前
版本与 Build 信息。

## 背景与问题

现有设置以遮罩和浮层打开，空间受限且与桌面应用的全局配置语义不一致。维护者提供 Codex
设置页和 QuotaView 关于页截图，要求设置成为应用内的全局页面，并让版本信息有稳定、可发现
的入口。

## 目标

- G-001：设置打开后形成完整、稳定的应用级页面，而不是居中浮层。
- G-002：保留现有设置项、分区导航和配置文件动作的功能。
- G-003：新增符合 DeepViewer 品牌的关于页，并从真实包元数据生成版本信息。

## 非目标

- NG-001：不改变 Harness 设置持久化格式、RPC 或插件契约。
- NG-002：不新增账号、更新检查、遥测、外部链接或自动发布能力。
- NG-003：不执行本地预览封包、签名、公证或正式发布。

## 用户与用例

### UC-001：进入和退出设置

用户从侧栏底部打开设置，窗口内容切换为带返回入口的全局设置页面；点击返回或按 Escape
回到原工作区，原会话状态不受影响。

### UC-002：浏览设置分区

用户通过左侧导航切换通用设置、模型、插件、Agent 预设等既有分区，右侧内容保持独立滚动，
浅色和深色主题使用现有设计 token。

### UC-003：查看应用信息

用户从导航最下方进入“关于 DeepViewer”，看到应用图标、DeepViewer 名称、简短产品说明，
以及与桌面包一致的版本号和 Build 编号。

## 功能需求

- R-001：设置 surface 必须占满应用内容视口，不显示背景遮罩、浮层圆角或悬浮阴影；左侧导航
  与右侧内容必须构成稳定的两列全局页面。
- R-002：全局页面必须提供清晰的返回应用入口，并保留 Escape 退出、分区切换、配置文件动作
  和现有设置控件行为。
- R-003：“关于 DeepViewer”必须固定在导航底部，显示 DeepViewer 图标、名称、产品说明、版本
  和 Build 编号；版本信息必须由 `apps/deepviewer-desktop/package.json` 的当前元数据生成。
- R-004：设置定制必须保存在 DeepViewer 跟踪源码中，由上游覆盖同步脚本确定性写入固定
  Harness checkout，并把现有 DeepViewer 图标复制到 Web 构建公共资源。

## 非功能需求

- NFR-001：不得新增运行时第三方依赖或扩大 preload / IPC 接口。
- NFR-002：页面必须支持主窗口最小尺寸，导航和内容各自保持可用滚动，不得遮挡返回入口。
- NFR-003：沿用 Harness 字体、图标和主题 token，满足键盘焦点、语义标题和可访问名称要求。

## 验收条件

- AC-001：Given 任一工作区状态，When 打开设置，Then 设置占满应用内容视口并呈现左侧导航、
  右侧内容，不出现背景遮罩、居中浮层圆角或阴影。
- AC-002：Given 设置已打开，When 切换既有分区、点击返回或按 Escape，Then 分区内容正确切换，
  返回后会话状态保留，既有设置控件和配置文件动作仍可使用。
- AC-003：Given 打开“关于 DeepViewer”，When 查看品牌信息，Then 显示项目现有图标、名称、
  中英文产品说明和由桌面包清单生成的当前版本与 Build 信息。
- AC-004：Given 全新固定 Harness checkout，When 执行覆盖同步和 build，Then 设置页面、关于页
  与图标资源可确定性恢复，相关测试、类型检查和 production build 通过。
- AC-005：Given 浅色/深色与最小/常规窗口尺寸，When 维护者逐页检查设置，Then 导航、内容、
  文本层级、滚动和交互均可接受。

## 边界与失败行为

- 上游目标文件、公共资源目录或模板占位符不匹配时，同步脚本必须失败并指出覆盖项。
- 设置分区动态卸载时回退到第一个仍存在的分区；空分区列表保持可退出的空内容页面。
- 关于页只展示编译时包元数据，不读取系统、账户、工作区或会话数据。

## UX 说明

整体结构参考 Codex 的全局设置页面：左侧为固定导航，右侧为宽松内容画布，当前分区标题在
内容顶部。页面不复制 Codex 的全部设置、搜索或分类，只采用其应用级信息架构。关于页参考
QuotaView 的居中品牌层级，但使用 DeepViewer 自有图标、文案和版本信息。

## 数据、安全与隐私

不新增持久化字段、外部请求、遥测或个人数据读取；关于页元数据来自仓库包清单。现有 Renderer
sandbox、context isolation、导航限制和设置 RPC 边界保持不变。

## 风险

| 风险 | 影响 | 缓解方式 |
| --- | --- | --- |
| 全屏 surface 仍泄漏模态视觉或焦点 | 体验与目标不一致 | 移除 mask、圆角和阴影，保留明确返回焦点与 Escape 路径 |
| 关于页版本与安装包不一致 | 用户误判版本 | 同步脚本从桌面 `package.json` 生成显示文本 |
| 上游设置实现变化 | 覆盖失效 | 全文件受控覆盖、目标断言、契约测试与 build 失败即停 |
