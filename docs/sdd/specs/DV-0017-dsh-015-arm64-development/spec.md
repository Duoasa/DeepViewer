# DSH 0.1.5-rc.2 ARM 开发适配

维护者于 2026-09-14 直接授权：以 GitHub 发布的 DeepViewer 稳定版适配 DSH 0.1.5-rc.2，放弃 x86，仅支持 ARM；先完成开发版，只做冒烟测试，实机验收由维护者完成。该指令批准本规格范围，状态为 Implementing。

## 基线与范围

- DeepViewer：GitHub Latest 非 prerelease 条目 `v0.2.3`，标签提交 `25de065bc8fbee885696c4c3da0ca14158fa687b`。发布说明仍称其公开预览；本次按 GitHub 正式发布条目选定基线。
- DSH：`dsh-v0.1.5-rc.2`，提交 `fb2c4b9e698e30edb738bca4cf0618587db7d203`。
- 保留基线桌面功能、品牌、窗口、设置、Finder 文件操作以及订阅插件；预览改用 DSH 官方实现。
- 不合入 0.2.4 灵动岛预览改动。维护者随后授权将本轮适配发布为 GitHub Preview，仅发布 ARM 安装包。
- 发布标识为 `v0.2.5-preview.1`，应用版本 `0.2.5` / Build 1；GitHub 为 Pre-release，不替换稳定版 Latest。
- 公开 Preview 使用独立 `DeepViewer Preview/0.2.5-preview.1` 数据目录；开发版继续使用原开发目录。新生成 ARM Runtime、签名 DMG、公证票据与 SHA-256 清单，进行包体与启动冒烟。真实账户与交互仍由维护者验收，不运行完整回归。

## 需求

- R-001：开发和构建绑定上述 DSH 精确版本与提交，拒绝错配上游。
- R-002：macOS 支持范围为 arm64；开发、Runtime 和封包入口不得默认生成或接受 x64。
- R-003：通过受控覆盖与插件扩展点适配客户端变化，不改写上游 Agent 循环。
- R-004：DVP-0001 `dsh-plugin-subscriptions@0.3.1` 继续启用并保留禁用开关。按维护者补充指令，预览使用 DSH 官方实现，停止挂载 DVP-0002；右上角展开/收起及全屏按钮保留现有显式操作与状态切换逻辑。
- R-005：开发启动只创建一个本地 DSH Web Runtime，由 Electron 接管页面，不自动打开系统浏览器。
- R-006：开发数据与已安装版本及先前开发版本隔离；不自动导入、迁移或覆盖用户会话和凭据。
- R-007：按后续授权发布 v0.2.5-preview.1；只提供新生成的 ARM64 签名公证 DMG 与校验清单，使用独立 Preview 数据目录，并保留 v0.2.3 Latest。
- NFR-001：保留工作区路径限制、loopback 鉴权、官方预览资源权限与 CSP 和窄 preload/IPC 权限。
- NFR-002：仅构建与冒烟，不运行全量测试、真实付费模型调用或替代维护者实机交互验收。

## 验收

- AC-001（R-001、R-003）：锁定上游的 host/client/Web 和 DeepViewer 开发构建成功。
- AC-002（R-002）：开发宿主为 arm64；Runtime/封包入口拒绝 x64；默认架构唯一为 arm64。
- AC-003（R-004、NFR-001）：默认插件组合启动冒烟通过，插件加载有证据；禁用组合可启动。插件 PC-001—PC-009 记录本次边界，未测项保留 Pending。
- AC-004（R-005、R-006）：隔离开发目录启动到 Runtime ready，页面资源可读取，正常停止后无该次遗留 Runtime。
- AC-005（NFR-002）：视觉、会话真实调用、订阅账户登录/用量/登出、文件预览与 Finder 操作由维护者实机验收，保持 Pending Manual。
- AC-006（R-007）：ARM 安装包的结构净化、签名公证、独立启动冒烟与 GitHub 远端资产校验有记录；不生成 x64 安装包。

## 风险与回退

DSH 客户端接口和持久化格式跨版本变化较大，不能只更新版本号。旧的受控覆盖必须迁移到当前上游接点，构建失败或插件未激活不得记为通过。开发使用独立目录；回退为退出本开发版并使用原 v0.2.3，不将新数据目录交给旧核心。
