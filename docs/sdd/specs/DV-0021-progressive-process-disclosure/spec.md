# 渐进式过程披露

维护者确认方案后以“你来施工吧”授权实施。沿用当前开发版图标、字体、主题和布局，不实施此前探索的整体 UI 改版。

- R-001：紧凑会话中默认突出当前操作；并行操作显示真实数量并可展开。已完成的思考、搜索与读取、命令执行、文件修改、子代理及其他操作分类收起。
- R-002：正文、最终答复、失败/中断、审批和提问不因过程折叠而隐藏。复用官方记录和工具渲染，不推测 Bash 命令的用途，不改 Agent Loop 或持久化记录；普通会话模式和轨迹页保留原行为。
- R-003：仅当前活动文字显示中性流光；完成、等待交互、停止时停止；遵循减少动态效果。保留手动展开状态，不因后续操作更新而收回正在查看的详情。
- R-004：按会话/轮次隔离折叠状态，保留事件锚点、完整详情、键盘操作和现有审批入口。未知操作保守保留。

## 实施与验收

- T-001（R-001、R-002）：增加纯展示分类与聚合，通过现有 keyed Chat Node 源订阅真实生命周期；复用原图标和详情组件。
- T-002（R-003、R-004）：稳定记录身份、分类披露与流光样式，接入官方 pending interaction 状态。
- T-003（全部）：分类/流式更新/并行/失败与中断/混合正文/手动展开测试，核心类型检查和实际客户端构建，更新开发版。
- AC-001：工具完成无需新增节点即可从当前操作进入正确分类，计数不重复；并行操作可查看。
- AC-002：混合思考与正文不隐藏正文；失败、提问和审批仍可处理；暂停状态不流光。
- AC-003：分类及已展开详情在新操作和生命周期迁移后保持；会话隔离、键盘展开、减少动态效果有效。
- AC-004：开发版实际加载新核心构建；视觉及真实任务人工验收仍待维护者确认。
