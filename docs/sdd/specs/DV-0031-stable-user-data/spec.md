# DV-0031 — 固定用户数据目录与升级连续性

Status: Implementing
Approval: 维护者于 2026-09-22 明确授权开发 0.3.3，采用程序与数据分离、固定分渠道目录、数据结构独立版本的设计，完成后构建并重启开发版。

- R-001: 安装版固定使用 Application Support/DeepViewer，开发版固定使用 Application Support/DeepViewer Dev；应用版本、预览版本和 DSH 版本不得参与数据路径。
- R-002: 首次启动自动导入本渠道旧版本目录，合并会话、附件和工作区登记；配置采用最近实际使用的数据源。保留旧目录和迁移前快照，冲突保留在备份中并记录报告。
- R-003: 桌面目录布局使用独立 schemaVersion 和事务记录；先复制及校验再切换，失败不启动空白内核，中断可恢复。DSH 会话格式迁移继续由其原有持久化层管理。
- R-004: 完成导入后不再重复扫描旧目录，后续应用与内核升级原地使用数据。显式测试目录不导入真实数据，开发版与安装版互相隔离。
- R-005: 冷启动、迁移或缓存失效后，Work/Chat 分类、标题与搜索仍从持久会话恢复；无工作区的 Chat 不被列表过滤，不依赖逐条打开会话。
- NFR-001: 不修改旧目录、用户工作区文件、模型凭据内容或上游 agent loop；备份权限限制为当前用户。并发旧实例、未知格式及不安全链接导致导入停止并显示可重试错误。

## Acceptance

- AC-001: 固定目录、渠道隔离、显式目录隔离、版本无关的单元测试通过。
- AC-002: 多旧目录及已有目标目录合并、字节一致性、工作区登记、冲突备份和幂等测试通过。
- AC-003: 中断恢复、并发实例、源数据变化、链接、未知 schema 与格式失败保护测试通过。
- AC-004: 0.3.3 开发版构建并重启；本地数据数量及内容摘要校验、DSH 就绪和再次启动冒烟通过。
- AC-005: 维护者手动确认旧会话、设置及附件在界面中连续可用（Pending Manual）。
