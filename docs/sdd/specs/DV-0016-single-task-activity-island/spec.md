# DV-0016：单任务灵动岛

## 摘要

在 DeepViewer `0.2.4` 开发版中加入集成在主窗口标题栏中央的 macOS 单任务灵动岛。它被动显示当前选中 Harness
会话的权威运行状态，复用 QuotaView 稳定版的显示开关、粒子球/波澜光晕、完成后缩小和
缩小后隐藏四类设置，但不引入 Codex Hook、连接向导或多任务岛。

## 背景与问题

DeepViewer 已经拥有本地 Harness Runtime 和会话连接，因此再次要求用户配置外部连接会产生
重复状态源和失败路径。用户希望先验证一个稳定、克制的单任务方案：在应用内直接看到当前
任务是思考、执行工具、等待确认、完成还是失败，并能在设置中控制它的动画和收起节奏。

## 目标

- G-001：提供跟随当前选中 Harness 会话、附着于主窗口标题栏中央的非交互 macOS 灵动岛。
- G-002：使用现有 Runtime/Session 状态作为唯一权威来源，不要求额外连接。
- G-003：原样迁移 QuotaView 稳定版单任务岛的窗口、材质、排版、状态色、动画以及四类用户
  设置和默认值，只替换活动数据源与产品文案。
- G-004：把功能作为 `0.2.4` 开发版实现并完成基础自动验证。
- G-005：以独立源码预览分支和预发布标签公开实现，供用户自行编译，同时保持 `v0.2.3`
  公开版代码与标签不变。
- G-006：让标题栏中央的 token 摘要固定在展开态灵动岛下方的靠下位置，不随岛缩略或隐藏
  上移，同时让岛以无底色内容层无缝嵌入标题栏；浅色、深色主题分别使用深色、浅色高对比前景。

## 非目标

- NG-001：不显示、排序或切换多个后台任务。
- NG-002：不加入 QuotaView/Codex Hook、连接测试、授权或断开连接界面。
- NG-003：不改变 Harness agent loop、会话协议或模型调用行为。
- NG-004：不在本规格中生成安装包、签名、公证产物，也不把源码预览合并为 `v0.2.3` 或
  稳定版 Release。
- NG-005：不在 Windows/Linux 上模拟 macOS 灵动岛窗口。

## 用户与用例

### UC-001：观察当前任务

- 参与者：正在使用 DeepViewer 的 macOS 用户。
- 前置条件：灵动岛已开启，用户选择一个会话。
- 主流程：会话开始运行时主窗口标题栏中央的岛展开；状态变化时更新短文案和动画；等待确认
  保持展开；完成后按设置缩小并隐藏。
- 失败/退出流程：Runtime 失败时显示不可用状态；关闭设置后窗口立即隐藏。

### UC-002：配置灵动岛

- 参与者：macOS 用户。
- 前置条件：打开 DeepViewer 设置。
- 主流程：在独立“灵动岛”设置页开启/关闭显示，选择粒子球或波澜光晕，并设置完成后缩小、
  缩小后隐藏的延迟。
- 失败/退出流程：非法或损坏的持久化值回退到安全默认值。

## 功能需求

- R-001：系统必须只投影当前选中的一个 Harness 会话；切换会话时必须替换岛内容，不显示多
  任务列表、切换控件或后台任务队列。
- R-002：系统必须从现有 Runtime 与当前会话快照推导状态，不得要求 Hook、连接测试、凭据或
  额外授权步骤。
- R-003：系统必须至少区分待机、思考、执行、等待确认、完成、错误和 Runtime 不可用状态；
  有待确认交互时必须优先于普通运行状态，运行中的工具调用必须优先于思考状态。
- R-004：新任务或活动状态变化必须展示展开态；完成、错误或待机状态必须按“完成后缩小”
  延迟进入紧凑态，再按“缩小后隐藏”延迟隐藏；新的活动必须取消旧计时并重新展开；等待确认
  不得自动隐藏。
- R-005：设置中必须新增独立“灵动岛”分区，包含：显示开关（默认开）、动画选择（粒子球，
  默认；波澜光晕）、完成后缩小（默认 `20` 秒，`5...60` 秒，步长 `5`）和缩小后隐藏
  （默认 `100` 秒，`5...120` 秒，步长 `5`）。不得显示连接相关设置。
- R-006：设置必须保存在桌面 userData 中并在应用重启后恢复；写入前必须做枚举、范围和步长
  归一化，损坏文件不得阻止应用启动。
- R-007：灵动岛必须是附着到 DeepViewer 主窗口、透明、不可聚焦、鼠标穿透且不出现在
  Dock/任务切换器中的普通 macOS 子窗口；不得使用会跨应用或跨 Space 浮动的原生 `panel`
  类型。它必须以主内容区标题栏安全区域为锚点居中，并跟随主窗口移动、缩放、侧栏宽度和
  可见性及焦点变化；主窗口失焦时必须隐藏，重新聚焦后才可恢复，不再跨应用置顶。
- R-008：粒子球和波澜光晕必须有可辨识的不同视觉；系统“减少动态效果”启用时必须使用
  静态表现，岛隐藏时必须停止动画帧。
- R-009：Runtime 页面到主进程只能发送经校验的状态枚举、会话标识、有限长度标题、时间戳
  和序号；不得传递提示词、回复正文、工具参数或凭据。
- R-010：DeepViewer 桌面包开发版本必须更新为 `0.2.4` Build `1`；根 workspace 版本继续遵循
  `v0.2.3` 发行基线，不伪装成应用发布版本。
- R-011：对固定 Harness checkout 的活动发布器和设置页改动必须来自 DeepViewer 跟踪的
  `upstream-overrides/`，并由同步脚本确定性恢复。
- R-012：迁移必须以 DeepViewer `v0.2.3` 和固定 Harness `0.1.1-rc.2` 为基线，保留全局设置、
  预览与订阅插件、品牌槽位及 rc.2 原生凭据行为，不得回退到旧 Harness 或旧设置壳。
- R-013：公开源码预览必须使用独立分支 `DV/preview-0.2.4-activity-island` 与不可变的顺序预发布
  标签；当前修订使用 `v0.2.4-preview.2` 并保留 `v0.2.4-preview.1` 历史标签。不得移动
  `v0.2.3` 标签或更新 `main`，并必须明确说明只提供源码、本地编译步骤及人工视觉验收边界。
- R-014：当前会话 token 摘要必须镜像到主内容标题栏中央、固定在展开态灵动岛下方的靠下位置；
  必须保持原有会话顶栏高度，统计行与“对话 / 轨迹”标签文字行垂直对齐并和底部分隔线保留间距，不得通过增加 safe-area 高度
  撑大会话顶栏；岛在紧凑或隐藏状态下统计行不得跟随上移，也不得回到输入框下方或重复显示。
- R-015：岛不得绘制 surface 底色、边框、背景模糊或容器阴影；浅色主题必须使用深色主文字，
  深色主题必须使用浅色主文字。两种主题都必须保持原有状态色、层级、可读性和 QuotaView
  球体、排版、尺寸与动画参数。
- R-016：设置页的粒子球和波澜光晕预览必须直接运行岛使用的同一个 WebGL 2 renderer、shader、
  状态参数和减少动态效果策略，不得使用 CSS gradient、静态图片或另外手绘的近似图。
- R-017：展开态进入紧凑态时，岛窗口必须以展开态几何中心为固定中心同时收缩四边，不得保持
  顶边不动而向顶部缩小。

## 非功能需求

- NFR-001：保持 `contextIsolation`、sandbox、导航限制和最小 preload bridge；所有 Renderer
  输入必须由主进程再次校验。
- NFR-002：不得增加运行时第三方依赖；岛动画采用 QuotaView 的 60fps 上限，并避免在隐藏时
  消耗 CPU/GPU。
- NFR-003：窗口和设置控件必须具有无障碍名称，颜色不作为唯一状态信号。
- NFR-004：状态机、设置归一化和自动收起计时必须可用确定性单元测试验证。
- NFR-005：Runtime 页面发布的标题栏锚点只能包含经主进程校验的有限数值坐标和尺寸，不得
  扩大 preload 权限或允许 renderer 直接控制窗口选项。

## 验收条件

- AC-001：Given 灵动岛开启且当前会话开始运行，When 会话从思考进入工具执行，Then 顶部
  单个岛展开并从思考切换为执行状态，且没有多任务 UI。
- AC-002：Given 当前会话产生待确认交互，When 运行状态同时仍为真，Then 岛显示等待确认且
  在交互解决前不自动缩小或隐藏。
- AC-003：Given 会话完成且延迟分别为 20 秒和 100 秒，When 计时推进，Then 岛先在 20 秒
  进入紧凑态，再在其后 100 秒隐藏；期间新活动会立即重新展开并重置计时。
- AC-004：Given 用户打开设置，When 选择灵动岛分区，Then 可见四类 QuotaView 同款设置而
  不见连接设置，修改值会立即生效并在重启后恢复。
- AC-005：Given 用户切换粒子球与波澜光晕，When 岛可见，Then 两种动画的视觉表现明确不同；
  减少动态效果或隐藏状态下不持续请求动画帧。
- AC-006：Given Runtime 页面尝试发送非法状态、超长标题或越界设置，When 主进程接收，Then
  非法活动被拒绝，设置被归一化，且任何消息正文或工具参数都不进入岛接口。
- AC-007：Given macOS 主窗口可见，When 主窗口移动、缩放、切换侧栏/详情栏宽度、最小化或
  切换到其他应用，Then 岛始终在主内容区标题栏安全区域居中、随主窗口隐藏/恢复，并在主窗口
  失焦时立即隐藏且不因后续状态更新重新置前，同时保持鼠标穿透、不可聚焦。
- AC-008：Given 干净的固定 Harness rc.2 checkout，When 运行覆盖同步、类型检查、单元测试和
  生产构建，Then `v0.2.3` 的全局设置与两个 Active 插件保持可用，灵动岛发布器、设置页、
  桌面桥与第二窗口均可复现，桌面版本显示为 `0.2.4` Build `1`。
- AC-009：Given `v0.2.3` 公开版，When 发布源码预览，Then 预览分支与标签可追溯到
  `v0.2.3`，GitHub 仅包含源码和编译说明，不上传应用包或 DMG，且 `main` 与 `v0.2.3` 不变。
- AC-010：Given 会话已有 token 统计，When 灵动岛展开、缩小或隐藏，Then token 摘要只在
  主内容标题栏靠下的固定位置显示，并与“对话 / 轨迹”标签文字行垂直对齐，不随岛上移、不在
  输入框下方重复出现；会话顶栏与迁移前高度一致，统计行不贴住底部分隔线且不进入消息滚动区。
- AC-011：Given 系统或应用在浅色、深色主题间切换，When 岛可见，Then 岛保持完全透明的
  容器背景，并分别使用深色、浅色文字；球体、状态点和文字动画在两种主题下均清晰可辨。
- AC-012：Given 用户打开灵动岛设置页，When 查看两种动画选项，Then 两张卡片中的状态球由
  岛的实际 WebGL renderer 实时绘制，且与岛共享 shader 和状态参数。
- AC-013：Given 岛处于展开态，When 自动收起进入紧凑态，Then 展开与紧凑窗口的几何中心
  保持一致，四条边同时向中心收缩。

## 边界与失败行为

- 没有当前会话、灵动岛关闭或非 macOS 平台时不创建可见岛。
- 主窗口隐藏、最小化或退出时岛同步隐藏；恢复显示后根据最后状态和设置重新显示。
- 当前会话切换时旧会话后续变化不应重新占用岛；新会话快照成为唯一显示来源。
- 设置文件不存在或解析失败时使用默认值；持久化失败记录诊断但不使主窗口退出。
- Runtime 页面刷新、重连或临时无快照时允许隐藏岛，下一次权威快照到达后重新展开。
- 岛 renderer 加载失败不得影响主窗口或 Runtime 生命周期。

## UX 说明

展开态保留 QuotaView 稳定版的 `10pt` 外层留白、原版状态点/三行排版和按状态变化的原始
窗口尺寸，但不绘制 HUD surface、底色、描边、模糊或容器阴影，使球体与文字直接嵌入
DeepViewer 标题栏空白区域；浅色主题采用深色文字，深色主题采用浅色文字；
紧凑态使用原版 `270×72pt` 窗口、`250×52pt` surface、`28pt` 球体与居中状态标题。粒子球
和波澜光晕使用 QuotaView 同一组状态色、运动参数和球体半径；不为 DeepViewer 重新设计岛
样式。岛是只读的环境反馈，不接收点击、键盘或拖动。主内容列保持原有会话顶栏高度；摘要以
无底板单行文字固定在顶栏底部分隔线上方，不新增结构高度。设置页沿用 DeepViewer 设置面板的
交互控件，但状态球直接运行岛的实际 renderer，
设置语义、范围和默认值与 QuotaView 一致。

## 数据、安全与隐私

持久化数据只有启用布尔值、动画枚举和两个整数延迟。运行时 IPC 仅传递会话 ID、有限长度显示
标题、状态枚举、时间戳和递增序号；这些数据只留在本机内存，不写日志、不上传。提示词、模型
回复、工具参数和文件内容不进入此功能。token 摘要只在 Runtime renderer 的现有 DOM 内做
同页文字镜像；Token 与凭据不进入灵动岛 IPC、主进程、日志或持久化。凭据继续完全由 rc.2
Harness 现有 provider 处理，灵动岛不增加解析、迁移或写入路径。

## 风险

| 风险 | 影响 | 缓解方式 |
| --- | --- | --- |
| 上游会话快照结构变化 | 状态投影停止或构建失败 | 受控覆盖、严格锚点、类型检查和同步测试 |
| 附着窗口干扰主界面 | 遮挡点击、抢焦点或跨应用浮动 | 普通 child window、鼠标穿透、不可聚焦、随主窗口隐藏，禁止原生 `panel` 类型 |
| 高频 Renderer IPC | 能耗或状态乱序 | 仅在派生快照变化时发布，主进程校验递增序号 |
| 计时器竞态 | 旧任务隐藏新任务 | 单一协调器拥有计时器，新活动统一取消并重建 |
| 布局变化导致锚点漂移 | 岛与主内容区不居中 | ResizeObserver 发布有限锚点，主进程校验并统一重定位 |
