# Runtime 与官方 DSH Web 权限一致性

维护者直接要求本地 Runtime 和网页权限与 DSH Web 一致，并确认范围包含 Agent 文件、命令、网络以及网页文件选择、剪贴板。该指令批准本规格目标。维护者进一步确认：跟随官方权限选择，工作区模式按官方审批，完全访问模式按官方放行。

已确认根因：官方 base bundle 读取 DSH_PERMISSION_MODE 设置 sandbox-policy.mode 和 approval.policy；桌面旧环境白名单遗漏此变量，导致显式初始权限回退为官方默认。

## 需求和实施方案

- R-001：沿用官方 `dsh web` 的沙箱、审批和会话权限设置；不添加权限覆盖 patch，不强制完全访问，不修改既有会话权限。
- R-002：本地子进程像直接启动 DSH 一样继承启动环境，取消桌面环境变量白名单；保留运行必需的 ELECTRON_RUN_AS_NODE、隔离 DSH_HOME、关闭遥测和日志颜色设置。环境不写入日志或产物。
- R-003：沿用官方网页的文件选择、上传与剪贴板入口及 Chromium 安全隔离；保留 contextIsolation、sandbox、webSecurity 和窄 IPC，不通过给网页 Node 权限实现对齐。
- NFR-001：OS 授权属于 macOS 对应用的独立授权，不能复制终端/浏览器的授权；不迁移 ~/.dsh 或覆盖用户数据。浏览器与桌面的已保存站点授权不共享。

## 验收及任务

- T-001 / AC-001（R-001、R-002）：验证自定义工具环境、代理与凭据环境继承，桌面必需变量仍固定，原环境不被修改；启动参数无额外权限覆盖，插件失败回退使用同一环境。
- T-002 / AC-002（R-003）：核对官方文件选择和剪贴板调用，运行既有窗口安全配置冒烟，保持网页安全隔离。
- T-003 / AC-003（全部）：开发构建及启动冒烟；维护者实机验收原生文件选择、复制/粘贴、Agent 文件/命令/网络及权限切换，保持 Pending Manual。

## 风险和回退

继承环境使 Runtime 可用启动进程持有的工具配置和凭据，与直接启动 DSH 一致；不代表赋予网页直接读取环境的权限。Finder 启动的环境仍可能不同于终端，macOS TCC 授权也可能不同。回退恢复环境白名单，不改变数据目录或会话。
