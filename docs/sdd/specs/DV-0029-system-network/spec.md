# DV-0029 — 自动系统网络适配与内网授权

Status: Implementing
Approval: 维护者于 2026-09-22 要求全面修复网页抓取/搜索网络问题，自动识别网络环境，并指出内网访问应通过弹窗授权。

- R-001: 桌面启动的 DSH 自动跟随系统 HTTP/HTTPS/PAC/SOCKS 路由，新连接重新解析路由，无须用户填写端口或重启内核。
- R-002: 显式进程及 DSH home .env 代理配置优先；保留既有 DSH 优先级与 loopback bypass，继续拒绝项目 .env 中的代理配置。
- R-003: 网页访问本机/内网目标由桌面授权弹窗决定，提供拒绝、仅本次、本次运行内允许此目标；授权绑定主机、端口、解析地址集合。直接连接固定已验证地址，DNS 变化重新判断，每一跳重新检查。
- R-004: 代理不可达、DNS、TLS、超时和用户拒绝产生可区分的脱敏诊断；不自动重放付费搜索 POST、不静默绕过代理直连。
- NFR-001: 中继仅监听随机 loopback 端口，使用短期随机鉴权；不共享浏览器 Cookie、不记录请求内容/密钥；退出关闭连接。
- NFR-002: 不改变 DSH 0.1.5-rc.2 Agent Loop；现有冻结 0.3.1 Build 68、DMG、标签不变。本轮仅开发修复与测试，不提交或发布。

## Acceptance
- AC-001: 对照测试证明 GitHub/raw fake-IP 场景经过系统代理成功；直连和代理路由变化不需重启 DSH。
- AC-002: 显式代理/.env/NO_PROXY 优先级、PAC 路由、错误分类测试通过。
- AC-003: 未授权 loopback/内网无请求发出；同目标授权有效，目标/IP 变化重新授权；无鉴权请求被拒绝。
- AC-004: 类型检查、构建、相关回归及隔离 Host/运行时冒烟通过；真实付费搜索与弹窗交互由维护者验收。
