# Design

R-001/R-002: 桌面拥有临时鉴权 HTTP 中继；普通运行时请求通过标准代理接口，公开网页工具通过专用 GET 转发接口。系统路由由 Electron session.resolveProxy 按连接查询，支持系统代理/PAC，不硬编码 Surge 端口；显式 DSH 代理保持优先。旧连接完成，新连接使用当前路由。

R-003/NFR-001: 普通模型/MCP 网络沿用其既有权限；网页接口逐目标解析、判断和授权。公网 DIRECT 固定解析 IP；受信系统代理负责 fake-IP 域名的远端解析。真实内网/loopback 或非公网字面地址须用户同意；授权不扩大到其他主机或新解析地址。网页转发只传工具自己的 Accept/User-Agent，不携带浏览器会话。

R-004: 网络中继记录主机/端口与白名单错误码，不记录 URL 查询、用户信息、请求体或代理凭据。网页错误以结构化错误返回 DSH；搜索沿用原 API，仅修复传输并补充底层错误码。

变更属于桌面网络边界适配，不升级内核或插件版本。兼容性范围：DVP-0001 subscriptions、DVP-0003 reasoning、DVP-0004 better-sidebar。只在源码/构建副本增加适配，不修改已签名的应用或冻结 Runtime。
