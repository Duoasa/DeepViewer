# 默认文件附件交付

维护者直接要求：以后每次使用 DeepViewer，生成文件必须以最终回复下的附件卡片交付；不转换、迁移历史输出。

- R-001：宿主统一注入文件交付规则，适用于图片、视频、音频、文档及其他文件；必须先保存实际文件并调用 present，路径文字或操作记录不等于交付。
- R-002：通过已有工具生命周期自动登记可确定的成功产物（image_generate 的返回 paths、write 和编辑器 create 的写入路径），不依赖模型重复调用 present；显式 present 对相同文件更新说明而不重复显示。
- R-003：继续使用原生附件卡片、侧栏预览、打开及 Finder 操作；不修改 Agent loop；允许把生成工具的文件路径归一为工作区交付路径，不解析任意输出文字或扫描用户目录猜测产物。
- NFR-001：只登记当前会话当前轮次真实可访问的普通文件；失败、取消、读取调用不登记。对无法从工具协议确定路径的 Bash/第三方工具，依赖统一 present 指令，不宣称任意工具都可自动发现。
- NFR-002：目标 DSH 0.1.5-rc.2；保留当前本地派生与 Active DVP-0001、DVP-0003、DVP-0004；权限、鉴权和原生打开校验不变。

## 验收
- AC-001：全局交付规则可从 systemPrompt assemble 读取；插件卸载后规则消失。
- AC-002：生成工具不调用 present 时，成功路径自动产生同轮 deliverables/presented 事件；失败、缺文件、读取、取消不产生事件。
- AC-003：现有附件去重、预览及受鉴权打开测试通过；新规则由 owned overrides 在开发与 Runtime 构建中保留。
- AC-004：开发构建通过并重启；视觉和真实生成由维护者检查。

## 工作区交付修复（2026-09-21，维护者明确授权）

- R-004：内部附件对象是模型输入缓存，不能直接充当用户交付文件；生成工具的原始文件与 present 指定的外部文件必须在当前工作区 outputs 中物化后再登记。
- R-005：读取文件实际签名决定图片后缀，保留原始字节与原图质量；安全命名、内容校验和排他创建确保重复交付复用同一文件且不覆盖用户文件。
- R-006：同一生成结果的缓存路径、附件对象路径、工作区路径归一到同一卡片；模型收到的生成路径亦指向工作区。归一映射持久化于交付事件的可选 sourcePaths 字段，不迁移旧日志。
- NFR-003：只写当前 Session 工作区；只读模式、缺工作区、目录逃逸、符号链接、取消与失败不生成成功交付事件，不关闭侧栏 workspaceFence。
- AC-005：复现带后缀外部原图与无后缀哈希对象两种输入；验证落盘字节、真实后缀、会话去重、模型路径与卡片路径一致。
- AC-006：隔离真实 DSH Host 冒烟验证交付路径在 workspaceFence 开启时返回 HTTP 200/image/png 和正确字节，匿名与越界仍拒绝；只做自动化冒烟，最终效果由维护者确认。
