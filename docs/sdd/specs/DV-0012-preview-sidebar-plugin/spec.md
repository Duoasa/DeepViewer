# DV-0012：代码与实时网页预览侧栏插件

## 摘要

为 DeepViewer 增加固定版本的第一方 DSH 预览插件，在现有右侧详情列中提供工作区文件树、只读
代码高亮和隔离的静态网页预览，同时保留原工具详情。附件方案仅作为设计输入；本规格直接实现
目标态详情标签扩展，不落地临时主区标签页。

## 目标

- G-001：从会话页一键打开真正的右侧预览栏。
- G-002：安全浏览当前已登记工作区的文本代码并预览静态网页。
- G-003：DSH 修改文件后自动刷新，也允许用户随时手动刷新。

## 非目标

- NG-001：不编辑文件，不提供终端、命令执行或应用内开发服务器。
- NG-002：首版不加载用户输入的任意 URL，不探测本机端口。
- NG-003：不修改 DSH agent loop，不封包、签名、公证或发布。

## 功能需求

- R-001：右侧详情列必须提供可扩展标签位；内置“工具”和插件“预览”可切换，工具选择仍打开
  工具详情，关闭/拖拽/会话切换沿用现有布局行为。
- R-002：软件窗口右上角必须提供位置固定的本地化预览开关，与左侧栏开关共享顶部系统安全区；
  点击后打开右栏并选中预览标签，再次点击收起当前预览右栏。
- R-003：预览插件只能列出和读取当前会话对应的已登记工作区；目录按需展开，工作区文件标题栏
  整行均可展开或收起文件区，文本文件只读展示并复用应用通用代码高亮和字体。
- R-004：文件访问必须拒绝越界、符号链接逃逸、敏感路径、二进制文件、超限文件和非法请求；
  单文件上限为 1 MiB，单目录最多返回 1,000 项。
- R-005：选择 HTML 文件或工作区根 `index.html` 时可切换到网页预览；静态资源根固定在入口文件
  所在目录，使用短期 capability URL、no-store 响应和 sandbox iframe。网页预览必须提供独立标题栏和
  基础浏览器工具栏，支持站内后退、前进、刷新、受限地址跳转及在系统浏览器打开当前预览；标题栏
  同时作为工作区文件区与网页区的高度拖动热区。
- R-006：成功文件产出事件必须对代码内容和网页 iframe 进行去抖刷新；工具栏同时提供手动刷新。
- R-007：无已登记工作区、无文件、无可预览 HTML、读取失败和能力不可用时必须显示可恢复状态，
  不能使会话或 DSH 核心失效。
- R-008：插件必须固定为 `@deepviewer/dsh-plugin-preview@0.1.0`，开发态与 Runtime 使用相同构建
  产物，并登记到 DSH 插件兼容清单。

## 非功能需求

- NFR-001：目标内核固定 DeepSeek Harness `0.1.0-rc.7`；新增槽位保持 additive。
- NFR-002：Host RPC 仅允许 loopback authority；预览数据不得进入 Electron preload/IPC 或日志。
- NFR-003：中英文、深浅主题、键盘焦点和按钮可访问名称使用现有 DSH 体系。
- NFR-004：插件缺失、禁用或预检不通过时跳过预览并保留订阅插件与纯核心回退链。

## 验收条件

- AC-001：窗口右上固定预览开关不随会话标题或右栏宽度移动，并避开 macOS 顶部安全区；点击后
  右栏打开并显示“工具 / 预览”标签，选择工具行仍切回工具详情。
- AC-002：已登记工作区可按需展开目录、选择文本文件并获得带正确语言提示的只读高亮内容；点击
  “工作区文件”标题栏任意位置均可展开或收起文件区。
- AC-003：越界、外链符号链接、敏感路径、二进制或大文件请求均被确定性拒绝且不泄露内容。
- AC-004：选择 HTML 后网页在隔离 iframe 中加载同目录静态资源；网页标题、地址、后退、前进、刷新、
  系统浏览器打开和标题栏拖动均可用，地址跳转不能离开当前 capability 静态根，任意外部 URL 不能
  作为入口。
- AC-005：DSH 成功修改文件后，当前代码和网页自动刷新；手动刷新在无产出事件时仍有效。
- AC-006：插件被禁用、缺失或不兼容时，应用继续以订阅插件或纯核心启动并记录无敏感诊断。
- AC-007：相关测试、类型检查、桌面构建和上游 Web 构建通过；视觉与交互由维护者人工验收。

## 边界与失败行为

- 非已登记工作区会话显示不可用状态，不接受 Renderer 自报的任意绝对路径。
- 静态站脚本不能获得父页面同源权限；外部网络访问默认由预览 CSP 拒绝。
- 自动刷新不承诺捕获 DSH 之外的编辑器写入，用户可手动刷新。
