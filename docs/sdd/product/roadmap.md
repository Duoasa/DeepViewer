# 路线图

路线图表达阶段顺序和验证目标，不代表固定发布日期。每个阶段在开发前仍需拆成独立的 `DV-NNNN` 规格。

## Phase 0：项目与上游基线

- 建立 SDD、贡献和决策记录体系
- 评估 DeepSeek Harness 的接入与更新策略
- 确定目标平台、桌面技术栈和最小发行方式
- 建立许可证、第三方通知和品牌边界

退出条件：上游集成与应用外壳方案已有批准 ADR，最小工程可以构建和测试。

## Phase 1：可运行的桌面外壳

- 启动、配置和连接本地 Harness
- 创建会话并提交任务
- 展示流式输出、运行状态和基础错误
- 安全保存非敏感用户设置

退出条件：新用户可以完成并复查一个端到端本地任务。

## Phase 2：可观察、可控制的 Agent 工作区

- 任务时间线和工具活动视图
- 文件变更、终端输出和产物预览
- 权限请求、暂停、取消、重试和失败恢复
- 会话搜索、命名和历史管理

退出条件：关键执行状态和高影响操作具有清晰 UI 与自动化验证。

## Phase 3：定制与插件体验

- 模型、插件、预设和工作流管理
- UI 扩展点与插件呈现契约
- 可导入导出的配置和团队模板
- 插件兼容性与故障隔离

退出条件：至少一个第三方扩展无需修改 DeepViewer 核心即可安装和使用。

## Phase 4：可靠发行

- 跨平台安装包、签名和更新
- 崩溃恢复、诊断导出和隐私控制
- 性能、无障碍与安全基线
- 稳定版迁移和兼容承诺

退出条件：发布、升级和回滚路径均有重复验证的证据。
